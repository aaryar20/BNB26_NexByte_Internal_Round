# CreatorAI Backup Demo

## Demo Flow

1. Open CreatorAI Dashboard
2. Create Project
3. Upload Recording
4. Add / View Script
5. Run AI Analysis
6. Review AI Suggestions
7. View Best Clips
8. Select Clip
9. Open Editor
10. Configure Captions / Audio / Aspect Ratio
11. Preview Platform Output
12. Render Video
13. Export Final MP4

## Critical Demo Path

Upload → Analyze → Generate → Edit → Render → Export

## Backup Strategy

If live AI or video rendering fails during judging:

1. Show the working frontend workflow.
2. Show previously generated AI results.
3. Show a previously rendered final MP4.
4. Show the recorded end-to-end product demo.
5. Explain the architecture and integration between the AI backend and FFmpeg video engine.
